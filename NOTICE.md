# Источники данных

Скрипты загружают открытые списки IPv4 CIDR из проекта
[`GrimbirdUsers/ru-routing-dat`](https://github.com/GrimbirdUsers/ru-routing-dat).
В upstream-репозитории на момент публикации не указана лицензия. Файлы upstream
не включены в этот репозиторий: они загружаются пользователем непосредственно с
GitHub. `config/route-policy.json` содержит только проверенные допустимые границы,
которыми ограничивается автоматическое обновление.

MIT License в этом репозитории относится к исходному коду и документации этого
проекта, а не предоставляет прав на сторонние данные.

Опциональный генератор полного Amnezia JSON также загружает зафиксированный по
commit и SHA-256 список доменов из
[`kozlovartem20201/amnezia-vpn-russia`](https://github.com/kozlovartem20201/amnezia-vpn-russia).
В этом upstream на момент интеграции лицензия также не указана. Сам список не
включён и не перелицензирован этим репозиторием: пользователь получает его
непосредственно с GitHub автора. Обновление pinned commit выполняется только
после ручной проверки нового снимка.

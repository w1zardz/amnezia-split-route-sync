# Проверка russia.iplist.opencck.org

Проверено 2026-09-12 через интерфейс сайта и его публичные выгрузки.
Для ручного импорта в AmneziaWG подходит **Amnezia → IP-зоны IPv4 (CIDR)**.
Однако формат файла не подтверждает, что все его сети нужны для российского direct.

| Выгрузка всех порталов | Записей | Наблюдение |
|---|---:|---|
| IPv4 CIDR | 1449 | После точного объединения 1368 сетей, 42 299 418 адресов |
| Отдельные IPv4 | 8761 | Даже после объединения 7483 маршрута |
| Домены, wildcard-фильтр включён | 250 | У всех записей пустое поле IP |

В общей CIDR-выгрузке присутствовали `11.0.0.0/8`, `54.64.0.0/11`,
`4.192.0.0/12` и `13.32.0.0/12`. Это значительно шире адресов отдельных сервисов.
По текущей таблице IP→ASN первые адреса этих диапазонов относились соответственно
к DNIC, Amazon, Microsoft и Amazon, со страной US.

Сайт описывает сбор зон через WHOIS и ipcalc; зона владельца адреса не равна
проверенному списку российских сервисов. В интерфейсе отсутствие выбранных
порталов означает выгрузку **всех**, а не пустого набора.

Поэтому этот источник остаётся кандидатом для ручной проверки выбранных порталов.
Общая выгрузка не подмешивается в ежедневный релиз. Ручные домены и CIDR нашего
каталога сохраняются независимо от фильтра внешних данных. Пользовательские
записи в Amnezia также не следует удалять при обновлении управляемой части.

Источники: [интерфейс](https://russia.iplist.opencck.org/ru/),
[описание механизма](https://russia.iplist.opencck.org/ru/about/),
[код и настройки источника](https://github.com/rekryt/iplist),
[проверенная CIDR-выгрузка](https://russia.iplist.opencck.org/?format=amnezia&data=cidr4).
Данные источника меняются; приведённые числа относятся к указанной дате.
